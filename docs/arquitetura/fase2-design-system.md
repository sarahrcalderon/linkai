# Fase 2 — Design System

- Cores: esmeralda para ações principais, neutros slate para superfícies.
- Temas: atributo `data-tema` no elemento raiz; preferência salva localmente.
- Tipografia: Inter com fallback para fontes do sistema, corpo 16 px.
- Componentes: `Botao`, `CampoTexto`, `Cabecalho`, `CartaoIndicador` e `GraficoCliques`.
- Acessibilidade: foco visível, rótulos associados, feedback de erro e gráfico com descrição textual.
- Dados do painel: **fictícios**, sem integração com a API nesta fase.
- Telas de autenticação e navegação autenticada ficam para a fase de autenticação, evitando formulários sem função.
